# Vocabulario

Личный Telegram-бот для изучения испанской лексики. Интерфейс русский, словарные значения и переводы примеров английские. Код написан специально для этого проекта; открытые боты изучены как образцы, готовая библиотека повторений — FSRS.

## Что работает

- Предзагружены **5 000 карточек** (4 941 различное написание; отдельные карточки для разных частей речи), **32 темы**, 14 520 связей «карточка — пример». У каждой карточки есть значение, IPA и 2–3 примера с переводом и указанием авторов.
- Кнопка «🔎 Найти слово»: напишите испанское слово или английское значение. Также доступны просмотр по темам, личная отметка «Учить» и список выбранных слов.
- 535 карточек глаголов с таблицами из базы Fred Jehle, включая основные времена изъявительного и сослагательного наклонений, условные и повелительные формы. Для выбранных глаголов не подставляются догадки о спряжении.
- Кнопка произношения: синтезированная речь через онлайн-сервис Edge TTS, локальный кеш MP3. По умолчанию испанский Испании.
- 12 оригинальных простых картинок для casa, sol, luna, árbol, manzana, pera, libro, mesa, silla, huevo, flor, montaña. Это стартовый набор, иллюстрации пока есть не у каждого слова.
- Утреннее и вечернее занятия, по умолчанию **09:00 и 20:00 по Москве**, до 15 вопросов за сессию. Кнопка **«⚙️ Расписание»** или `/settings` позволяет изменить время, выбрать дни недели, отключить один сеанс или приостановить все напоминания. Настройки сохраняются в SQLite. Бот присылает первый вопрос, если есть выбранные слова с наступившим сроком. `/review` позволяет продолжить самостоятельно.
- Обязательный письменный ответ, проверка ударений и ñ. Пять успешных написаний без подсказки с промежутками ≥24 часов открывают ручную отметку «Выучено».
- После отметки — проверка не раньше чем через 30 дней; ошибка возвращает активное изучение. SQLite сохраняет прогресс, открытый вопрос и журнал ответов после перезапуска.
- Один владелец, только личные сообщения; пауза напоминаний и экспорт прогресса.

## Запуск на Windows

Python 3.11 или новее. Команды из папки проекта, PowerShell:

```powershell
git clone https://github.com/viktorenkova/vocabulario.git
Set-Location vocabulario
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item .env.example .env
```

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Запишите токен в `TELEGRAM_BOT_TOKEN` в локальном `.env`. Токен не нужно отправлять в чат или коммитить.
3. Если ваш числовой Telegram ID неизвестен, временно оставьте `ALLOWED_USER_ID` пустым. Запустите бот и отправьте ему `/id`: в этом режиме доступна только эта команда.
4. Остановите процесс Ctrl+C, запишите полученный ID в `ALLOWED_USER_ID` и запустите снова:

```powershell
.\.venv\Scripts\python.exe -m vocabulario.bot
```

5. Отправьте `/start`, нажмите «🔎 Найти слово» и напишите интересующее слово. Откройте найденную карточку и нажмите «Учить». Затем `/review`. Для выбора по темам доступна `/topics`.

Словарь поставляется готовым; пересобирать его для запуска не нужно.

Бот работает, пока работает процесс и есть интернет. Выключенный или спящий компьютер не отправляет сообщения. Для постоянной работы предусмотрен образ Docker; развёртывание на сервере ещё не выполнено. После запуска позднее назначенного времени бот отправит только ближайшее прошедшее занятие за текущий день, если есть повторения; пропущенное утреннее занятие не дублируется вечером. Задолженность по словам сохраняется в очереди. Каждый сеанс отправляется не более одного раза за день, включая перезапуски.

## Настройка расписания в Telegram

Нажмите «⚙️ Расписание» или отправьте `/settings`. Нажмите утреннее или вечернее время и введите новое в формате `ЧЧ:ММ`, например `08:30`. Ввод времени не засчитывается как ответ на открытый вопрос по слову. У каждого сеанса есть отдельная кнопка включения/выключения; выбранное время сохраняется и при отключении.

Дни с галочкой включены. Можно переключать каждый день отдельно или выбрать «Каждый день», «Будни», «Выходные». Если выключены оба сеанса или исключены все дни, автоматические сообщения не приходят; ручное повторение остаётся доступным. Общая пауза не сбрасывает выбранные часы и дни. Время указано для Москвы; часовой пояс по-прежнему задаётся через `TIMEZONE` при первом создании расписания.

## Команды

| Команда | Назначение |
|---|---|
| `/topics`, `/words` | Темы и весь словарь |
| `/search`, `/search casa` | Написать слово для поиска или искать сразу |
| `/my` | Выбранные слова |
| `/review` | Начать/продолжить повторение |
| `/cancel` | Завершить текущий вопрос как «не помню» |
| `/stats` | Статистика |
| `/settings` | Время и дни утреннего/вечернего занятия |
| `/pause`, `/resume` | Выключить/включить ежедневные занятия |
| `/export` | JSON с прогрессом и историей |
| `/id`, `/help` | ID и помощь |

Без открытого вопроса обычный текст тоже запускает поиск. Во время вопроса текст считается ответом; нажмите «🔎 Найти слово» или отправьте `/search`, чтобы перейти к поиску. Открытый вопрос сохраняется, продолжить его можно кнопкой «📚 Повторить». Если результат поиска показывает проверяемое слово, ответ по этой карточке считается ответом после подсказки.

## Повторение и ограничения

Основание и сравнение репозиториев: [docs/research.md](docs/research.md). FSRS рассчитывает интервалы по ответам, целевая вероятность удержания по умолчанию 0,90. Это параметр модели, а не обещание 90% запоминания.

Поверх FSRS действуют явно заданные правила продукта: активный материал после удачного ответа возвращается не позже следующего настроенного занятия, чтобы его можно было повторить утром и вечером. Выученный материал сохраняет редкое расписание с минимумом 30 дней. Пять засчитанных написаний должны оставаться разнесёнными минимум на 24 часа: утренний и вечерний ответы одного дня не дают два зачёта в порог освоения. Эти пороги и ограничение следующего сеанса — проектные решения, не универсальные результаты эксперимента. После ошибки повторение становится доступным через 10 минут; получить его можно командой `/review`, отдельное уведомление через 10 минут не отправляется.

Подсказка, открытие карточки, спряжения, картинки или аудио текущего слова лишают этот ответ зачёта. Повторный ответ спустя меньше 24 часов не увеличивает счётчик. Регистр и лишние пробелы игнорируются, но año/ano и sí/si различаются. Синонимы не принимаются автоматически: упражнение проверяет конкретную карточку. Темы и примеры не разделяют все значения многозначных слов; примеры отобраны по лемме, а не по смыслу.

IPA взята из экспериментального автоматического источника `ipa-dict`, не прошла ручную проверку всех карточек. Темы формируются из списков слов, ключевых слов значений и WordNet; 108 карточек остаются в общей лексике. Автоматическая классификация может ошибаться, это не подтверждённая разметка CEFR. Исходные словари могут содержать разговорную и грубую лексику. Русских переводов и полного покрытия картинками пока нет.

## Проверка и воспроизводимость

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[dev,data]'
New-Item -ItemType Directory -Force -Path runtime | Out-Null
.\.venv\Scripts\python.exe -m pytest -q --basetemp=runtime/pytest
.\.venv\Scripts\python.exe -m ruff check vocabulario scripts tests
```

Тесты проверяют письменный порог, подсказки, повторные ответы, восстановление после перезапуска, ошибки после освоения, ударения, доступ владельца, оба сеанса, дни недели, паузу, ввод времени, миграцию старого расписания и полноту словаря. Подключение к реальному Telegram требует токена и проверяется отдельно.

Пересборка словаря (нужен интернет; исходники примерно 90 МБ):

```powershell
.\.venv\Scripts\python.exe scripts/build_dictionary.py
.\.venv\Scripts\python.exe scripts/build_images.py
```

`data/sources.json` фиксирует Git commit и SHA-256 исходников. Сборщик повторно использует зафиксированные версии. Пакеты текущего проверенного окружения перечислены в `requirements-lock.txt`.

## Данные и размещение

Прогресс: `runtime/progress.sqlite3`; аудио: `runtime/audio/`; конфигурация: `.env`. Эти файлы исключены из Git. Для резервной копии остановите бот и скопируйте папку `runtime` вместе с `.env` в своё защищённое хранилище. `/export` дополнительно выгружает карточки и журнал, но автоматический импорт экспорта пока не реализован.

Docker — опциональный способ запуска на постоянном сервере:

```powershell
docker compose up -d --build
```

Эта команда здесь не запускалась. Образ использует тот же словарь, хранит прогресс в volume и перезапускает процесс при сбое. Не запускайте одновременно два экземпляра с одним токеном.
